Generate a structured study summary from the given topic, file, or pasted content.

The input is: $ARGUMENTS

If $ARGUMENTS is a file path, read the file first. If it is a topic or raw text, use it directly.

Produce a study summary with the following sections:

## Overview
A 3–5 sentence plain-English explanation of what this topic is and why it matters.

## Key Concepts
A numbered list of the most important concepts, each with:
- **Term / Concept**: one-line definition
- **Why it matters**: one sentence on its significance

## How It Works
A step-by-step or logical breakdown of the core mechanism, process, or idea. Use simple analogies where helpful.

## Common Misconceptions
2–3 things people often get wrong about this topic, with a brief correction for each.

## Quick-Reference Cheat Sheet
A compact table or bullet list of the most important facts, formulas, commands, or rules to memorize.

## Review Questions
5 questions to test understanding — mix of recall, application, and critical thinking. Include answers at the bottom.
