Build a structured presentation outline from the given topic or content.

The input is: $ARGUMENTS

If $ARGUMENTS is a file path, read the file first. If it is a topic or description, use it directly.

Create a presentation with the following structure:

1. **Title Slide** — a compelling title and one-line subtitle.
2. **Agenda** — 4–6 bullet points covering what the presentation will address.
3. **Slides** — for each agenda item, produce:
   - Slide title
   - 3–5 concise bullet points (no full sentences, presentation style)
   - A speaker note: 2–3 sentences expanding on the key message of that slide.
4. **Key Takeaways** — 3 memorable points the audience should leave with.
5. **Q&A / Closing Slide** — a closing statement and suggested discussion question.

Keep the tone professional and the language clear. Avoid jargon unless the topic demands it.
